# Så skriver du ett inlägg på Streetlights webbplats

Den här instruktionen är för dig som skriver Nyheter för föreningen. Du behöver inte kunna något om programmering. Du skriver i ett formulär i webbläsaren, och när du sparar uppdateras webbplatsen av sig själv inom några minuter.

Verktyget heter **Pages CMS**. Det är på engelska, så knapparnas engelska namn står inom parentes nedan.

## 1. Få åtkomst

1. Skaffa ett gratis konto på [github.com](https://github.com) om du inte redan har ett. Det är där webbplatsens texter och bilder sparas.
2. Be den som administrerar föreningens konto **streetlight-nu** på GitHub att ge dig skrivrätt till webbplatsen. Skicka ditt användarnamn på GitHub.
3. Gå till [app.pagescms.org](https://app.pagescms.org) och logga in med ditt GitHub-konto (Sign in with GitHub).
4. Välj webbplatsen **streetlight-nu/web**.

> **För administratören:** skrivrätt ges på GitHub under repot `streetlight-nu/web` › Settings › Collaborators and teams › Add people, med rollen *Write*. Första gången behöver appen Pages CMS också installeras för organisationen streetlight-nu; Pages CMS frågar efter det vid första inloggningen. Ta bort personen där när hen inte längre ska skriva.

## 2. Skriv ett nytt inlägg

1. Klicka på **Nyheter** i menyn till vänster.
2. Klicka på knappen för att lägga till ett inlägg (Add an entry).
3. Fyll i fälten:

| Fält | Vad du skriver |
| --- | --- |
| **Titel** | Inläggets rubrik. Måste fyllas i. Titeln blir också inläggets adress, till exempel `/nyheter/skolstart-i-addis-abeba`. Adressen ändras inte om du byter titel senare. |
| **Datum** | Dagen inlägget gäller. Måste fyllas i. Det nyaste inlägget visas först. |
| **Ämne** | Välj ett av de fyra: Rapport från Addis Abeba, Nyhet från föreningen, Berättelse från en familj eller Tack till faddrarna. |
| **Plats** | Var det hände, till exempel Addis Abeba. Får lämnas tomt. |
| **Ingress** | Ett par meningar som sammanfattar inlägget. Måste fyllas i. Den visas i nyhetslistan och när någon delar länken. |
| **Bild** | En bild överst i inlägget. Får lämnas tom. Ladda upp bilden i full storlek; webbplatsen gör själv mindre versioner. |
| **Alt-text** | Måste fyllas i när det finns en bild. Se avsnitt 4. |
| **Bilden visar barn** | Kryssa i om något barn syns på bilden. |
| **Familjen har gett sitt samtycke** | Se avsnitt 3. |
| **Exempelinlägg** | Lämna tomt. Det används bara för de påhittade exempelinläggen. |
| **Brödtext** | Själva texten. Du kan göra rubriker, fet stil, listor och länkar med knapparna ovanför textrutan, och lägga in fler bilder. |

4. Klicka på spara (Save). Inlägget publiceras på webbplatsen inom några minuter.

Vill du ändra ett inlägg öppnar du det under Nyheter, ändrar och sparar igen.

## 3. Samtycke

Utan familjens samtycke publicerar vi ingenting som visar ett fadderbarn eller en familj.

- Kryssa i **Familjen har gett sitt samtycke** bara när familjen faktiskt har sagt ja till att just den här bilden eller berättelsen publiceras.
- Webbplatsen **stoppar** ett inlägg som saknar samtycke om
  - ämnet är *Berättelse från en familj*, eller
  - **Bilden visar barn** är ikryssad, eller
  - det finns bilder i brödtexten.
- Webbplatsen kan inte se vad bilderna i brödtexten visar. Därför kräver varje inlägg med bilder i brödtexten samtycke, även om ingen familj syns. Kryssa i samtycket bara när familjen har sagt ja till bilderna.
- Skriv aldrig barnens efternamn, adress eller annat som gör att någon kan hitta familjen.

## 4. Alt-text

Alt-texten läses upp för den som inte kan se bilden, till exempel med skärmläsare. En bild utan alt-text stoppas.

- Beskriv kort vad bilden visar, som om du berättade det i telefon: *"Två barn i skoluniform på skolgården."*
- Börja inte med "Bild på" eller "Foto av".
- Bilder du lägger in i brödtexten ska också ha en beskrivning.

## 5. Om ett inlägg inte syns

Om ett inlägg bryter mot reglerna ovan, till exempel saknar alt-text eller samtycke, publiceras det inte, och webbplatsen fortsätter att visa det som fanns innan. Ingenting går sönder. Öppna inlägget, rätta det och spara igen. Syns det fortfarande inte efter en kvart, hör av dig till den som administrerar webbplatsen.

## 6. Ta bort exempelinläggen

Webbplatsen har fyra påhittade exempelinlägg som visar hur ett inlägg kan se ut. De är märkta "Exempel":

- Skolstart i Addis Abeba
- En verksamhet som bär familjen
- Välkommen till årsmötet
- Tack för ett år i skolan

När föreningens egna inlägg finns tar du bort dem:

1. Klicka på **Nyheter**.
2. Öppna menyn vid exempelinlägget och välj ta bort (Delete). Bekräfta.
3. Gör likadant med de andra.

När inget exempelinlägg finns kvar försvinner också notisen om exempel från nyhetslistan.

## 7. Fyll i Vår historia

Sidan **Vår historia** är en tidslinje från 1995 till idag. Allt som inte är ifyllt visas som ”fylls i”, så sidan går att publicera innan texterna är klara.

1. Klicka på **Vår historia** i menyn till vänster.
2. Skriv en **Ingress**: ett par meningar om hur allt började.
3. Under **Perioder** finns en rad per period, äldst först. Varje period har ett årtal, till exempel 1995–1999, ett kort namn och en sammanfattning.
4. Under varje period finns **Händelser**. Fyll i år, rubrik och text. Lägg till fler händelser med knappen för att lägga till (Add an entry).
5. Fältet **Att prata om tillsammans** är frivilligt. Där kan du skriva en fråga som en förälder kan prata om med sitt barn efteråt, till exempel ”Vad behöver du för att kunna gå till skolan?”.

Många läser sidan tillsammans med sina barn. Skriv därför med enkla ord och korta meningar, och gärna något konkret: en skola, en uniform, en vanlig dag. Berätta om barnen och familjerna med värdighet, och bara det de har gett sitt samtycke till.

### Foton på Vår historia och Om föreningen

Där det ännu inte finns något foto visar sidan en mörkgrön ruta med ett förslag på vilket foto som passar, till exempel ”Foto: Merry som liten, eller Tryggve hos Merrys familj”. Varje period i **Vår historia** har ett eget foto, och **Idag** har ett. På **Om föreningen** finns foton till *Så började det*, *Två föreningar, ett arbete* och *Vilka vi är*.

1. Öppna **Vår historia** eller **Om föreningen** och leta upp fältet, till exempel **Foto från perioden** under en period eller **Foto till Så började det**.
2. Ladda upp fotot under **Foto**, i full storlek. Webbplatsen gör själv mindre versioner.
3. Skriv en **Alt-text** (se avsnitt 4).
4. Kryssa i **Fotot visar ett barn eller en familj** om ett barn eller en familj syns på fotot. Kryssa då också i **Familjen har gett sitt samtycke**, men bara när familjen har sagt ja till just det här fotot.
5. Spara. Fotot ersätter rutan inom några minuter.

Samma regler gäller som för inläggen: ett foto utan alt-text, eller ett foto av ett barn eller en familj utan samtycke, publiceras inte (se avsnitt 5). Vill du ta bort ett foto tömmer du fältet **Foto**, så visas förslaget igen.

## 8. Fyll i julkampanjen

Sidan **Ge en julklapp** (`/julklapp`) är föreningens julkampanj. Belopp, insamlingsmål och betalning sköts av Repejo och syns direkt på sidan. Det som föreningen själv fyller i visas som ”fylls i” tills det finns.

1. Klicka på **Julkampanjen** i menyn till vänster.
2. Skriv **Sista dagen att ge en julklapp med kort**, som du vill att det ska stå, till exempel ”20 december”.
3. Skriv **Det här gör julklappen**: en eller två meningar om vad pengarna går till.
4. Fältet **E-post för frågor om julkampanjen** är frivilligt. Lämnar du det tomt visas föreningens kontakt-e-post.
5. Bocka i **Visa julkampanjen på startsidan och i menyn** när kampanjen pågår. Då syns ett kort avsnitt om julklappen direkt under de 20 ljusen på startsidan, och länken **Julklapp** i menyn. Bocka ur rutan efter jul, så försvinner båda. Sidan Ge en julklapp finns kvar för den som har en länk.

## 9. Skriv Vanliga frågor

Sidan **Vanliga frågor** (`/vanliga-fragor`) svarar på det som blivande faddrar brukar undra. Varje fråga är en egen post, precis som ett inlägg i Nyheter.

1. Klicka på **Vanliga frågor** i menyn till vänster. Där finns alla frågor.
2. Öppna en fråga för att ändra den, eller lägg till en ny (Add an entry).
3. Fyll i fälten:

| Fält | Vad du skriver |
| --- | --- |
| **Fråga** | Som en besökare skulle fråga, till exempel ”Hur väljs barnen ut?”. Måste fyllas i. Frågan blir också dess adress, till exempel `/vanliga-fragor#fraga-hur-valjs-barnen-ut`. Adressen ändras inte om du formulerar om frågan senare. |
| **Grupp** | Att vara fadder, Barnen och familjerna eller Föreningen. |
| **Ordning** | Lägre tal visas först i gruppen: 1, 2, 3 … Lämnar du det tomt hamnar frågan sist. |
| **Svar** | Själva svaret. Du kan göra listor och länkar med knapparna ovanför textrutan, men inte lägga in bilder. Lämna det tomt tills svaret finns, så visas ”fylls i av föreningen”. |

4. Klicka på spara (Save).

Några svar saknas än och visas som ”fylls i av föreningen”: vad det kostar, hur man betalar, hur man slutar och om man kan bli medlem.

**Föreningsuppgifter i ett svar.** Skriv inte Swish-numret eller e-posten direkt i ett svar. Skriv i stället namnet inom klammerparenteser, så hämtas uppgiften från **Föreningsuppgifter**. Då räcker det att ändra den på ett ställe. Saknas uppgiften visas ”fylls i”.

| Skriv | Så visas |
| --- | --- |
| `{swish}` | Swish-numret |
| `{epost}` | Kontakt-e-posten, som en länk |
| `{kontaktperson}` | Kontaktpersonen |
| `{organisationsnummer}` | Organisationsnumret |
| `{nittiokonto}` | 90-kontot |
| `{arsredovisning}` | Länken ”Läs årsredovisningen” |

Ett felstavat namn, till exempel `{bankgiro}`, stoppar sidan. Då fortsätter webbplatsen att visa det som fanns innan (se avsnitt 5). Rätta stavningen och spara igen.

**Startsidan** länkar till frågan ”Hur vet jag att pengarna når fram?” under Insyn. Tar du bort den frågan försvinner länken.
